## 5. Perubahan kode dan tes

- Validator domain bersama `UnicodeText` menolak U+0000 di posisi mana pun dan unpaired surrogate, lalu diterapkan pada `InputRules`, `RetentionRules`, `ImportMetadataValue`, `CaseRules`, validasi request JSON, dan metadata multipart.
- Parser CSV mengabaikan baris fisik kosong tanpa mengubah quoted multiline; validasi record dan batas 5.000 tetap dihitung dari record yang tidak diabaikan.
- Validasi raw `referenceCaseIds` membandingkan UUID sebagai identitas, sehingga perbedaan kapitalisasi tidak lagi dideduplikasi diam-diam oleh generated `Set<UUID>`.
- Metadata `sourceFileName` menolak dot, dot-dot, path separator, dan drive prefix setelah trim; deskripsi OpenAPI dan dokumentasi API diperbarui, lalu client TypeScript diregenerasi dari kontrak resmi.
- Tes baru mencakup domain, HTTP POST/PUT/search/metadata, parser CSV, kontrak request, tooling header parsing, dan exit code subprocess probe.
- `package.json` menambahkan `npm run test:tooling` dan memasukkannya ke `npm run verify`.
