## 2. Perbaikan FS-01

### 2.1 Perubahan kode

Atribut HTML `maxLength` dihapus dari seluruh field yang batasnya dinyatakan dalam **Unicode code point**:

| Berkas | Field | Batas |
| --- | --- | ---: |
| `packages/frontend/src/components/search/FindPrecedentsPage.tsx` | Complaint narrative pencarian | 50.000 |
| `packages/frontend/src/components/cases/CaseForm.tsx` | Complaint narrative | 50.000 |
| `packages/frontend/src/components/cases/CaseForm.tsx` | Handling notes | 10.000 |
| `packages/frontend/src/components/cases/CaseForm.tsx` | Evaluation notes | 10.000 |
| `packages/frontend/src/components/cases/CaseForm.tsx` | Company | 500 |
| `packages/frontend/src/components/cases/CaseForm.tsx` | Company response | 2.000 |

Validasi code point yang sudah ada tetap menjadi satu-satunya batas:

- `textLength` di `packages/frontend/src/lib/format.ts` menghitung `Array.from(value).length`.
- `validateCaseForm` di `packages/frontend/src/lib/case.ts` menolak nilai di atas batas sebelum `onSubmit` dipanggil.
- `validate()` di `FindPrecedentsPage.tsx` menolak narasi pencarian di atas 50.000 code point sebelum request API.

Dengan demikian input tidak lagi dipotong oleh browser. Nilai berlebih tetap utuh di kontrol, menampilkan error, dan tidak mengirim request API. Ini berlaku untuk pencarian, pembuatan kasus, dan pengeditan kasus karena ketiganya memakai komponen yang sama.
